# CRM UI Modernization Project

## Project Overview

You are a Senior UI/UX Engineer, React Architect, and Design System
expert.

I have an enterprise CRM application that is already fully functional.
The business logic, APIs, database structure, workflows, permissions,
routing, and backend integrations are complete and should remain
unchanged.

This is **NOT** a feature development project.

Your objective is to completely modernize the application's user
interface while preserving 100% of the existing functionality.

Treat this as a professional UI redesign similar to Linear, Vercel,
Stripe Dashboard, Notion, and modern SaaS products.

## Primary Goal

Redesign the entire CRM into a clean, modern, minimalist interface using
**shadcn/ui** while preserving every existing feature.

### Core Principles

-   Do not change business logic.
-   Do not modify APIs.
-   Do not change database schema.
-   Do not remove features.
-   Do not introduce breaking changes.
-   Improve only UI, UX, responsiveness, accessibility, consistency, and
    maintainability.

## Deliverables

For every redesigned screen: 1. Explain UI improvements. 2. Preserve all
functionality. 3. Build reusable components. 4. Remove redundant code.
5. Deliver production-ready React + TypeScript code. 6. Follow shadcn/ui
best practices.

The final application should look and feel like a premium enterprise
SaaS platform built in 2026 while keeping the existing business logic
unchanged.
